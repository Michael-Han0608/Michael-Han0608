# Hi, I'm Michael 👋

I build local-first tools: browser extensions, command-line apps, and desktop software. I work mainly with TypeScript and Node.js, and care about practical workflows, cross-platform behavior, and reliable releases.

## Projects

### [Zhihu Sync](https://github.com/Michael-Han0608/zhihu-sync)

A browser extension and CLI for turning Zhihu collections, upvoted answers, and other content into a local Markdown knowledge base.

- Exports content from the browser and incrementally archives selected collections and upvoted answers.
- Connects a dedicated Edge profile to a local CLI through Native Messaging; the archiving workflow runs on macOS and Windows.
- Built on [download-zhihu](https://github.com/chouheiwa/download-zhihu). The automated archiver is currently a **Developer Preview**.

**Stack:** TypeScript · Node.js · browser extensions · Native Messaging · GitHub Actions

### [Telemetry Studio](https://github.com/Michael-Han0608/telemetry-studio) <sub>fork / contributions</sub>

An [upstream desktop editor](https://github.com/dekiller82/telemetry-studio) for adding GoPro GPS and performance overlays to video. My public fork includes work on bounded preview seeking and GoPro GPS handling.

**Stack:** TypeScript · Electron · React · FFmpeg

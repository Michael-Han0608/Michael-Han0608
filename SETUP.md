
```text

```

## 2. Enable the contribution animation

In the profile repository:

1. Open **Settings → Actions → General**.
2. Under **Workflow permissions**, select **Read and write permissions**.
3. Open the **Actions** tab.
4. Run **Generate contribution animation** once.
5. Confirm that the `output` branch has been created.

The workflow will run daily and whenever the `main` branch is updated.
